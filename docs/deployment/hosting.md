# Hosting & Storage Infrastructure

The system integrates cloud services to manage transactional database records and store research files securely.

---

## 1. Database Hosting (Supabase)

Our database is hosted on **Supabase** (running on AWS in the `ap-south-1` region). 

### Connection Pooler Configuration
To prevent the application from exhausting the database's max connection limits (especially during heavy queue loads or high web traffic), Laravel is configured to connect to Supabase's built-in transaction-mode pooler.

*   **Host:** `aws-1-ap-south-1.pooler.supabase.com`
*   **Port:** `6543` (Transaction Mode Pooler port)
*   **Database:** `postgres`

---

## 2. File Storage (Supabase Storage / S3)

Sensitive files (such as proposal documents and reviewer evaluation sheets) are stored in private Supabase Storage buckets. Access to these buckets is restricted.

### Configuration (`.env`)
The storage is configured as an S3 disk in Laravel's `config/filesystems.php`:

```ini
FILESYSTEM_DRIVER=s3
AWS_ACCESS_KEY_ID=your_supabase_s3_key
AWS_SECRET_ACCESS_KEY=your_supabase_s3_secret
AWS_DEFAULT_REGION=ap-south-1
AWS_BUCKET=urlc-documents
AWS_ENDPOINT=https://kntpskjnneezanjuybdd.supabase.co/storage/v1/s3
AWS_USE_PATH_STYLE_ENDPOINT=true
```

### Pre-signed Temporary URLs
Because the `urlc-documents` bucket is private, standard file links generated by `Storage::url()` will fail with access denied.

Instead, the application generates **temporary secure pre-signed URLs** that expire after a set time (e.g. 5 minutes). These are generated programmatically in our views and controllers:

```php
use Illuminate\Support\Facades\Storage;

// Generates a pre-signed URL valid for 5 minutes
$temporaryUrl = Storage::disk('s3')->temporaryUrl(
    $document->file_path, 
    now()->addMinutes(5)
);
```
Ensure all Blade files displaying research proposal documents use the temporary URL pattern rather than direct public asset links.
